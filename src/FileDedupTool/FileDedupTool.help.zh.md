# 一杯好茶.文件整理 · 使用说明

支持 Windows 10/11（64 位），免安装、免 .NET 运行库。下面几种情况要先处理，不然个别功能用不了：

- **32 位系统、Win7 及更早系统**：程序跑不起来，得换 64 位的 Windows 10/11。
- **没装 Everything**：专业版的顶部搜索会退回软件自带的扫描，能用，但慢一些。装上 Everything（voidtools 官网）并让它在后台运行，再重开本软件，搜索就会走 Everything，快很多。

> 按「点哪里 → 选什么 → 会发生什么」组织；文中按钮和选项均为当前界面实际存在。

## 一、这个软件能做什么

1. **查重（去重）**：把内容相同、或者内容很像的文件找出来，只留一份，其余删掉或做成硬链接（动手前可以先看清单）。
2. **按时间整理**：按拍摄时间或文件时间，把文件自动分进「年 / 月 / 日」文件夹。
3. **改文件名**：去掉文件名里多余的日期、序号、括号编号，把乱码文件名挑出来。
4. **上传蓝奏云**（可选）：把本地文件传到蓝奏云，网盘里已经有的同名同大小文件会被挑出来，不重复上传。
5. **AI 分析建议**（可选）：查重结果里，让 AI 帮你判断每组该留哪一个；它只给建议，删不删仍由你勾选。
6. **网盘查重**（专业版）：把网盘里的重复文件找出来，只按「同名 + 同大小」比，默认只列不删。
7. **自动更新**：启动时在后台看看 GitHub 上有没有新版本，有新版本才提示，你点了才下载替换。

所有会改动文件的操作，默认都先让你看清单，不会上来就删。

## 三、查重（去重）

### 3.1 怎么判断两个文件是「重复」

只有**内容完全一样**才算重复，和文件名无关。例子：

| 情况 | 算重复吗 | 原因 |
| --- | --- | --- |
| A.pdf 和 B.pdf 同名、同大小、内容一样 | 算 | 内容一致 |
| 两个文件同名，但大小不同 | 不算 | 大小就不一样 |
| 两个文件大小一样，内容不同 | 不算 | 内容不一致 |
| 两个文件名字完全不同，内容一模一样 | **算** | 查重只看内容，不看名字 |
| 两个 0 字节的空文件 | 算 | 都是空的；不想被删就把「最小大小」设成 1 |

扫描时程序会按「大小 → 内容」的顺序比，只有大小和内容都一致的才归为一组重复。真正删除前还会再核对一次文件有没有被改动：扫描之后又被改过或替换过的文件，会跳过不删。

### 3.2 三种去重开关

| 开关 | 什么算重复 | 默认 | 保留谁 |
| --- | --- | --- | --- |
| 内容去重：相同内容只留一份 | 文件内容完全一样 | 关 | 按「保留」下拉框的规则 |
| 相似图片去重 | 图片看上去几乎一样（连拍、轻微修图也能抓到） | 关，阈值 8（范围 0~20） | 按「图片保留」下拉框的规则，默认组里**文件最大**的那张；并列时路径短的 |
| 音频相似去重（实验） | 同扩展名，时长差不多 | 关，容差 2 秒（范围 0~60） | 按「保留」下拉框的规则 |

阈值怎么调：8 比较稳，只抓几乎一样的图；调到 12~16 会把连拍、轻微修图也算相似。调得过大容易误删。

### 3.3 保留哪一份：「保留」下拉框 4 项

内容去重和音频去重按这里的规则保留；相似图片按下方「图片保留」单独设置，默认保留体积最大的那张。

| 选项 | 拿什么比 | 并列时怎么办 |
| --- | --- | --- |
| 保留路径最短（默认） | 完整路径的字符数，最短的留下 | 长度相同 → 先扫到的留下 |
| 保留最新 | 文件的「修改时间」，最新的留下 | 时间相同 → 完整路径更短的留下 |
| 保留最旧 | 文件的「修改时间」，最早的留下 | 同上 |
| 保留文件名最短 | 只比文件名（不含文件夹）的字符数 | 长度相同 → 完整路径更短的留下 |

**图片保留（相似图片去重专用，独立设置）**：共 5 项，默认「体积最大」；改这里只影响相似图片分组，内容去重和音频去重仍按上面的「保留」规则。

| 选项 | 拿什么比 | 并列时怎么办 |
| --- | --- | --- |
| 体积最大（默认） | 文件字节数，最大的留下 | 字节数相同 → 完整路径更短的留下 |
| 保留最新 | 文件的「修改时间」，最新的留下 | 时间相同 → 完整路径更短的留下 |
| 保留最旧 | 文件的「修改时间」，最早的留下 | 同上 |
| 保留文件名最短 | 只比文件名（不含文件夹）的字符数 | 长度相同 → 完整路径更短的留下 |
| 保留路径最短 | 完整路径的字符数，最短的留下 | 长度相同 → 先扫到的留下 |

例子：同一组 3 个内容相同的文件 `D:\照片\a.jpg`、`D:\备份\2024\b.jpg`、`D:\备份\2024\c.jpg`；选「保留路径最短」留 `D:\照片\a.jpg`，删另外两个；选「保留最新」则比较修改时间，最新的留下，和路径长短无关。

### 3.4 删掉的东西去哪

| 选项 | 结果 | 能否撤销 | 怎么恢复 |
| --- | --- | --- | --- |
| 删除到回收站（可还原）（默认） | 文件进 Windows 回收站 | 能 | 点【撤销上次任务】，默认自动从回收站还原；也可手动去回收站右键「还原」 |
| 永久删除 | 直接删掉，不进回收站 | 不能 | 只能靠事先备份 |

撤销时：
- 移动、改名会按操作清单反向还原；
- 删除项到回收站里找，汇总分别显示「已从回收站还原 / 回收站中找不到 / 回收站已被清空 / 回收站还原失败」；
- 原位置已经有同名文件时**不覆盖**，记「还原失败：原位置已有同名文件」，回收站里的原件仍然保留。
- 不想自动还原，把「撤销时自动从回收站还原删除项」关掉即可，撤销时只提示去回收站手动取。

程序启动时会检测回收站能不能用（右上角【检测环境】也能看）。如果某个位置不支持回收站（比如部分移动盘、网络盘），勾「删除到回收站」的文件会**删除失败并写进日志**，不会偷偷改成永久删除。

### 3.5 哪些文件参与

| 选项 | 默认 | 生效后的影响 | 推荐 |
| --- | --- | --- | --- |
| 子文件夹 | 始终递归 | 没有「只扫当前层」的选项，一级一级全扫 | 无 |
| 跳过隐藏/系统文件 | 勾上 | 不勾 → 隐藏文件、系统文件也整轮参与 | 保持勾上 |
| 最小大小(KB) | 0（不限） | 设成 N → 小于 N KB 的文件整轮都不参与 | 照片视频设 1 以上，避免空文件被合并 |
| 排除文件夹 | 空 | 填名字（如 `@eaDir`）→ 任一层叫这名的目录整棵跳过；填完整路径（如 `D:\素材\原始`）→ 只跳过那个位置 | 把网盘缓存、软件工程目录排除掉 |
| 硬链接合并（不删数据） | 不勾 | 查重时不删重复文件，而是把它变成指向保留文件的硬链接：看着还在，实际不占额外空间；**仅同一个磁盘内有效**，跨盘、建链或删除失败时只跳过、不删 | 想省空间又怕丢文件时用；跨盘不要开启 |
| 整理后清理空文件夹 | 不勾 | 处理完把源文件夹里**完全为空**的子文件夹删掉；源根目录本身和目标的子目录不动 | 整理完想收干净时勾 |
| 保护词 | 空 | 文件名（不含扩展名）含这些词时，第一步/第二步不改名、第三步不删。**注意：它不影响内容去重和整理移动** | 填 `合同,身份证,论文` |

这张表里的「最小大小 / 跳过隐藏 / 排除文件夹」只作用于主界面的查重和五步流程。**按时间整理不看这些条件**：它会扫源文件夹里的全部文件（只跳过目录链接），所以整理前先在预览里看一眼。

硬链接的极端情况：极少数「建链后改名就位失败」时，那个重复文件的路径可能消失，但内容仍完整保存在保留文件里，数据不会丢。

### 3.6 先看后做：三种模式

| 模式 | 怎么开 | 会不会改文件 | 你会看到什么 |
| --- | --- | --- | --- |
| 先扫描预览再执行（推荐） | 默认勾上；只在勾了任一「去重」开关时生效 | 扫描阶段只读，不改 | 弹出「扫描结果预览」页 |
| 预演模式 | 勾「预演模式：只列出将执行的操作，不改动任何文件」 | **全程不改**，五步全部只写日志 | 日志里出现 `[预演] 将移动…` |
| 直接执行 | 取消「先扫描预览再执行」 | 确认弹窗后直接改 | 「开始前确认」弹窗，问你是否继续 |

预览页上这些按钮的作用：

| 按钮 | 做什么 |
| --- | --- |
| 全选/全不选（删除项） | 批量勾选/取消勾选要删的重复文件 |
| 执行完整流程（改名/整理照常） | 先按你勾的项删重复，然后一~五步照常执行 |
| 仅删除所选重复项 | 只删你勾的重复文件，跳过一~五步 |
| 导出 HTML 报告 / 导出 CSV 清单 | 把本次扫描结果存下来 |
| 取消（不执行） | 什么都不做 |

### 3.7 五个勾选框（第一步~第五步）与 9 个执行阶段

界面上「第一步 ~ 第五步」是 5 个主开关；「内容去重」「相似图片去重」「音频相似去重」「整理后清理空文件夹」是另外 4 个附加开关。每跑一次，程序按下面 9 个阶段执行，勾选框只决定哪些阶段参与。

| 步骤 | 默认 | 做什么 | 例子 |
| --- | --- | --- | --- |
| 第一步：去前缀序列号 | 开 | 去掉开头的日期、序号、括号序号、copy/副本字样；中间的 `(1)` 这类序号也会去掉 | `2024-01-15_报告.pdf` → `报告.pdf`；`01_照片.jpg` → `照片.jpg`；`(2)合同.docx` → `合同.docx`；`报告(1)终稿.docx` → `报告终稿.docx` |
| 第二步：去后缀序列号 | 开 | 去掉结尾的日期、序号、`(1)`、`副本`、`copy` 等 | `报告-1.pdf` → `报告.pdf`；`照片 (2).jpg` → `照片.jpg`；`总结 2024-01-15.xlsx` → `总结.xlsx` |
| 第三步：删除特殊文件 | **关** | 删掉八类「无意义文件名」的文件 | 见下表 |
| 第四步：去除只读属性 | 开 | 把源内文件的只读属性去掉，方便后面移动/删除 | 属性变化，名字不变 |
| 第五步：分类整理 | 开 | 按「整理方式」把文件搬进目标文件夹 | 见 3.8 |

**9 个执行阶段与开关的对应关系**：

| 序 | 阶段 | 对应界面开关 | 做什么 |
| --- | --- | --- | --- |
| 1 | 内容去重 | 内容去重：相同内容只留一份 | 内容完全相同的文件按「保留」规则每组留一份 |
| 2 | 相似图片去重 | 相似图片去重 | 按相似阈值分组，按「图片保留」规则每组留一张（默认体积最大） |
| 3 | 音频相似去重 | 音频相似去重（实验） | 同扩展名且时长在容差内，按「保留」规则每组留一份 |
| 4 | 第一步：去前缀序列号 | 第一步 | 同上面的步骤表 |
| 5 | 第二步：去后缀序列号 | 第二步 | 同上面的步骤表 |
| 6 | 第三步：删除特殊文件 | 第三步 | 同上面的步骤表 |
| 7 | 第四步：去除只读属性 | 第四步 | 同上面的步骤表 |
| 8 | 第五步：分类整理 | 第五步 | 按「整理方式」搬进目标文件夹 |
| 9 | 清理空文件夹 | 整理后清理空文件夹 | 只删空目录，不动有内容的文件夹 |

先后顺序：第 8、9 阶段固定在最后。第 1~7 阶段分两种情况——带预览保留结果执行时，先跑 1~3 再跑 4~7；直接在主界面执行时，先跑 4~7 再跑 1~3。参与阶段集合不变，只是顺序不同。

**第三步会删哪些**（默认关闭，开之前一定先预览或预演）：

| 类型 | 例子 |
| --- | --- |
| 全数字文件名 | `12345.txt`；**`20240115.jpg` 这类 8 位日期名不删** |
| 数字 + 恰好 2 个汉字 | `422536重生.doc`、`933768一梦`；**`照片2024` 这类纯年份名除外** |
| 字母 + 数字 + 恰好 2 个汉字 | `a1文件.docx` |
| 汉字夹在乱码字母数字中 | `HP之bug02wn8b2fa` |
| 含异常符号的乱码名 | `dc5bb5“夫` |
| 无意义字母数字组合 | `3f2a9c…`、`aec32yt72a3d93`、`owp44yoaf9d027` |
| 随机大小写字母串 | `tIqBkeIY` |
| 8 位以上无元音字母串 | `pkzhJhng`、`qwrtpsdfghjkl` |

不会被误删的：`DSC01234`、`IMG0001` 这类设备编号；`20240115` 这类日期名；`照片2024`、`会议记录` 这类正常中文名；`IMG_20240115_123456` 这种带下划线的名字；`报告-2024年总结`；`New Document` 这类带空格的英文短语。

**重要提醒（改名冲突）**：第一/二步改名后如果撞上已有同名文件，默认的「冲突时删除本文件」会**把正在改名的这个文件删掉**，即使两个文件内容不同。
例：`报告.pdf` 已存在，这时 `报告-1.pdf` 被简化成 `报告.pdf`，默认策略直接把 `报告-1.pdf` 送进回收站。
第一次用，建议先把冲突改成「冲突时自动重命名」或「冲突时保留两者」，或者先勾「预演模式」跑一遍看日志。

### 3.8 第五步的 5 种整理方式

| 选项 | 文件去哪 | 例子（目标 `D:\整理`） |
| --- | --- | --- |
| 按文件类型分类（文档/图片/压缩包…）（默认） | 按大类分文件夹；后缀大小写不敏感，多段后缀按最后一段判断；**不认识的后缀统一进「其他」**；括号标题落盘时改用纯文字名（见 3.10） | `报告.DOCX` → `D:\整理\文档\报告.DOCX`；`备份.tar.gz` → `D:\整理\压缩包\备份.tar.gz`；`数据.xyz` → `D:\整理\其他\数据.xyz` |
| 按文件后缀名整理（7Z / ZIP / JPG / DOCX…） | 每个后缀一个文件夹；括号标题落盘时同样改用纯文字名 | `照片.JPG` → `D:\整理\JPG\照片.JPG`；无扩展名 → `D:\整理\无扩展名\` |
| 按指定文件夹整理（全部移入同一个文件夹） | 全部进同一个目录；「指定文件夹」留空则进 `目标文件夹\整理结果` | `D:\整理\整理结果\` |
| 按文件名整理（关键字命中才移动） | 命中关键字的搬到目标文件夹根下，没命中留原地 | 关键字填 `报告,账单` → 只搬这两类到 `D:\整理\` |
| 按文件名字符特征整理（正则匹配才移动） | 正则命中的搬到目标文件夹根下 | 填 `^[A-F]` → 只搬首字母 A~F 的到 `D:\整理\` |

不确定关键字或正则写得对不对，可以点【规则测试器】：填一段文件名，它会告诉你哪些会被命中、会被改成什么名字，不会动任何文件。

### 3.9 撞名了怎么办：三种冲突策略（改名、移动、第三步共用）

| 选项 | 撞名时做什么 |
| --- | --- |
| 冲突时删除本文件（默认） | 目标已存在同名 → 把当前正在处理的文件删掉（按你的删除方式），保留已有的。内容不同也照删，务必看清楚 |
| 冲突时保留两者 | 撞名就跳过：不删、不覆盖、也不改名，原文件留在原地 |
| 冲突时自动重命名 | 撞名就顺延成 `名字 (1).ext`、`名字 (2).ext`，绝不覆盖 |

「冲突时保留两者」还有一个副作用：所有要删除的动作（第三步和查重删除）都会跳过，等于这次不删任何东西。

### 3.10 括号分隔的标题：判重 + 落盘改名

有些下载文件的标题被拆成一个个括号，例如 `(阳)(光)(故)(事)(会)(柒)(月)(不)(归)(离).mp4`。程序会把括号全部去掉，拼成 `阳光故事会柒月不归离`，这个纯文字标题既用于**判重**，也用于**整理落盘时的新文件名**：

- 括号数量**少于 3 对**：不还原，名字原样保留；只有一两个括号的正常名不会被改动。
- **3 对及以上**（全角 `（）`、半角 `()` 混用都算，空括号、嵌套、带空格都安全）：去掉所有括号字符后参与「同名/重复」判定。
- **整理到目标文件夹时**，文件名主干直接用纯文字标题，扩展名不变：
  `(阳)(光)(故)(事)(会)(柒)(月)(不)(归)(离).mp4` → 目标里是 `阳光故事会柒月不归离.mp4`。
  按时间整理、按文件类型分类、按文件后缀名整理、按指定文件夹/关键字/正则整理都遵循同一规则；预览清单的「目标文件名」列显示的就是最终落盘名字。
- **安全处理**：标题里出现 `\ / : * ? " < > |` 等非法字符 → 替换成下划线；去掉括号后为空 → 回退原文件名；主干超过 200 字符 → 截断并保留扩展名。
- **判重规则不变**：标题相同且内容相同 → 判为重复（移动模式把源文件移入回收站，复制模式只跳过、源文件保留）；内容不同 → 目标里按现有冲突策略处理，同名不同内容顺延 `名字 (1).ext`，绝不覆盖。
- **结果与日志**：改名幅度较大（原文件名主干 ≠ 目标文件名主干）的项，结果清单的「说明」列里会注明「已改为纯文字标题：原名 → 新名」。
- **撤销**：移动项可用【撤销上次任务】按操作清单还原，**能回到原来的括号文件名和原路径**；复制项本来就不自动撤销。

例：同目录里有 `阳光故事会柒月不归离.mp4` 和 `(阳)(光)(故)(事)(会)(柒)(月)(不)(归)(离).mp4`，两份内容一样 → 只保留一份，目标里叫 `阳光故事会柒月不归离.mp4`。

## 四、按时间整理

### 4.1 操作步骤

1. 点主界面「整理方式」分组最后的【按时间整理…】，打开独立窗口。
2. 选「源文件夹」和「目标文件夹」。两个不能是同一个，目标也不能在源里面。
3. 选「粒度」和「移动（默认）/ 复制（保留源文件）」。
4. 选「同名冲突」策略（默认内容比对去重）。
5. 点【扫描预览】（只读），列出每个文件会去哪。
6. 清单没问题，点【开始整理】。整理中想停下就点【停止】：已搬走的文件不会自己回来，仍可用【撤销本次整理】还原移动项。
7. 需要撤回就点【撤销本次整理】；要存档清单就点【导出清单】。

「扫描预览」不做完，【开始整理】是灰的，点不了。

### 4.2 粒度：目录长什么样

| 粒度 | 目录结构 | 例子（文件时间 2026-11-02 15:30） |
| --- | --- | --- |
| 按日（默认） | 年 / 年月 / 年月日 | `目标\2026\2026-11\2026-11-02\文件.jpg` |
| 按周 | 年 / 周 | `目标\2026\2026-W45\文件.jpg` |
| 按月 | 年 / 年月 | `目标\2026\2026-11\文件.jpg` |
| 按年 | 年 | `目标\2026\文件.jpg` |

按周时，一周从周一开始算，年份按这一周所属的年份。跨年例子：2025-12-29（周一）落在 2026 年第 1 周 → 目录是 `目标\2026\2026-W01\`。2025 年的照片放进 2026 文件夹属于正常结果。

### 4.3 时间从哪来

程序按下面的顺序找时间，前一个没有或明显不合理就用下一个：

1. 照片的拍摄时间（常见图片格式都支持）；
2. 视频自带的创建时间（mp4/mov 等常见格式）；
3. 文件的「修改时间」；
4. 文件的「创建时间」；
5. 都不行 → 放进 `目标\未知时间\`。

能用的时间范围是 1900 年到 2100 年，超出范围的（比如 1601 年那种假时间）当无效。文件全进了「未知时间」时，先看预览页的「时间来源」列再决定要不要继续。

### 4.4 移动 vs 复制

| 项目 | 移动（默认） | 复制（保留源文件） |
| --- | --- | --- |
| 源文件 | 搬走，源里不再有 | 原样留着 |
| 目标文件 | 出现一份 | 出现一份，修改时间尽量保持和源一致 |
| 磁盘占用 | 总量不变 | **翻倍**（源+目标各一份） |
| 能不能撤销 | 能，【撤销本次整理】搬回去 | **不能自动撤销**：避免程序误删你的副本，结果区会写「复制项不可撤销」 |
| 同名同内容时 | 删源进回收站 | 跳过，不重复复制，源保留 |
| 只读文件 | 自动先去掉只读再搬 | 直接复制，不动源 |

复制模式适合先验证整理效果、源文件绝对不能丢的场景。确认后自行删除源文件。

### 4.5 同名冲突：三种策略

| 下拉框里的选项 | 触发条件 | 结果 |
| --- | --- | --- |
| 内容比对去重（默认） | 目标位置已有同名文件 | 先比大小，大小相同再比内容 |
| 自动加序号（绝不覆盖） | 目标位置已有同名文件 | 一律改名 `名字 (1).ext`，内容不问 |
| 跳过（保留原文件） | 目标位置已有同名文件 | 不动，源留在原地，结果标「跳过」 |

「内容比对去重」的完整判断，一共 4 种结局：

| 情况 | 移动模式 | 复制模式 |
| --- | --- | --- |
| 同名 + 大小不同 | 视为不同 → 改名 `(1)` 放进去 | 同左 |
| 同名 + 大小相同 + 内容不同 | 视为不同 → 改名 `(1)` 放进去 | 同左 |
| 同名 + 大小相同 + 内容相同 | 源文件删进回收站，目标那份保留 | 直接跳过，源文件保留 |
| 没有同名 | 原名放进去 | 原名复制进去 |

### 4.6 只读、被占用、跨磁盘

| 情况 | 会怎样 | 观感 |
| --- | --- | --- |
| 只读文件 | 移动模式下先自动去掉只读属性再搬 | 正常完成 |
| 被别的程序占用 | 先列出占用该文件的进程名与 PID，问你要不要结束；你同意才结束**用户进程**（系统进程、资源管理器永不结束）。勾了「遇到占用自动尝试解除」就直接结束用户进程。解除后继续搬；失败/拒绝则这个文件标失败，**整批继续** | 默认弹确认框；日志出现「已解除文件占用」或「文件被其他程序占用，已跳过」 |
| 跨磁盘移动 | 系统先复制再删源，能完成，但慢 | 大文件会等比较久；中途断电/强制关闭可能留下半个副本 |
| 目标目录建不出来 | 该文件跳过，整批继续 | 日志「创建目录失败」 |
| 目标磁盘满了 | 该文件失败，整批继续 | 日志写失败原因 |

失败/跳过项会写一条日志，含时间、文件路径、原因、结果。

### 4.7 完成后打开文件夹 / 中途停止

**完成提示。** 整理成功后，窗口会弹出完成汇总，两个按钮：

| 按钮 | 作用 |
| --- | --- |
| 【打开目标文件夹】 | 用资源管理器打开**本次整理的目标根目录**，不是逐个打开子目录 |
| 【关闭】 | 只关提示，不动文件 |

移动、复制两种模式都一样：打开目标根目录。

**自动打开开关。** 主界面「设置 ▾」里的「任务完成后打开目标文件夹」和整理窗口里的「完成后自动打开目标文件夹」是同一个设置，默认**不勾选**，改任意一处另一处立即同步：

| 状态 | 完成后的行为 |
| --- | --- |
| 不勾选（默认） | 弹完成提示，你点【打开目标文件夹】才打开 |
| 勾选 | 下次完成直接打开目标根目录，不再弹可选提示 |

去重任务也一样：勾了第五步且填了目标文件夹时，打开的是目标根目录；没勾第五步时，打开的是源文件夹。

**不会自动打开的情况：** 任务被停止、执行失败、或本次 0 个文件。此时仍会弹提示，你手动点【打开目标文件夹】照样可以打开（目标目录确实不存在时会提示「未生成目标文件夹」）。

**底部状态提示。** 窗口右下角显示当前状态：空闲 / 进行中 / 已完成 / 已停止 / 已失败，由真实事件驱动。

**中途停止。** 主界面和整理窗口的【停止】是同一个含义：停止继续处理，**已经完成的文件不回滚**。

| 情况 | 结果 |
| --- | --- |
| 扫描预览中点【停止】 | 停止扫描，不打开结果页，状态显示「已停止」 |
| 主流程（改名/查重/整理）中点【停止】 | 当前文件处理完后停下，已完成的保留；移动项仍可用【撤销上次任务】还原 |
| 整理窗口点【停止】 | 同上；结果区/完成提示显示「已停止」，按钮恢复可点 |

这里的【停止】与结果页的【取消（不执行）】不是一回事：前者是任务跑起来之后停下来、保留已完成的结果；后者是执行前放弃本次任务，一个文件都不动。

### 4.8 撤销：能还原什么、不能还原什么

| 操作 | 用哪个按钮 | 能还原吗 | 还原到哪 | 特殊情况 |
| --- | --- | --- | --- | --- |
| 移动 | 【撤销本次整理】或【撤销上次任务】 | 能 | 回到原路径 | 目标文件已被你删了 → 记「目标已不存在」，跳过；原位置已经有新文件 → 记「原位置已占用」，不覆盖 |
| 复制 | 同上 | 不能 | — | 结果写「复制项不可撤销」 |
| 同名删源 | 无 | 能（默认自动从回收站还原） | 回收站 → 原路径 | 关掉自动还原后只能手动去回收站取回；永久删除就没了 |
| 查重删除 | 【撤销上次任务】 | 能（默认自动从回收站还原） | 回收站 → 原路径 | 汇总分别显示已还原 / 找不到 / 回收站已清空 / 还原失败 |
| 查重改名 | 【撤销上次任务】 | 能，反向改回原名 | 原文件名 | 撞名则跳过 |
| 去除只读 | 不能 | 属性不会自动恢复 | — | — |

撤销是按本次任务的操作清单逐条反向执行的。超长路径在清单里单独记录，撤销时自动回到原长路径。

### 4.9 这些情况会被直接拒绝

| 情况 | 提示 |
| --- | --- |
| 源文件夹不存在 | 「请选择有效的源文件夹。」/「源文件夹不存在：…」 |
| 源是整个磁盘根目录（如 `D:\`） | 主界面：「不建议直接处理整个磁盘根目录，请选择具体的文件夹。」；按时间整理：「不能把整个磁盘根目录作为源文件夹：…」 |
| 勾了第五步却没选目标 / 整理时没选目标 | 「勾选了第五步，请选择有效的目标文件夹。」/「请选择目标文件夹。」 |
| 源 = 目标 | 「源文件夹与目标文件夹不能相同。」 |
| 目标在源内部（如源 `D:\照片`、目标 `D:\照片\整理`） | 「目标文件夹不能位于源文件夹内部，请选择源文件夹之外的位置。」 |

## 五、上传蓝奏（可选）

### 5.1 第一次用：先登录

登录有两条路：**账号密码直连（推荐，默认走这条）**，以及接口调整或被风控时才用的**高级：粘贴密钥 / 粘贴 Cookie**。先试第一条，不行再走第二条。

1. 点底部【上传蓝奏】打开窗口。
2. 窗口顶部有平台下拉：**蓝奏云** / **蓝奏优享**，默认蓝奏云，会记住上次选择。
   两个平台的登录状态分开保存，切换平台不会串用。
3. 点【登录】打开登录窗口，走**账号密码直连（推荐）**：
   - **蓝奏云**：输入账号、密码，程序走 `accounts.woozooo.com` 登录接口，自动处理网页反爬参数，再收集 `ylogin`、`phpdisk_info` 会话；
   - **蓝奏优享**：输入账号、密码，程序走 `api.ilanzou.com/unproved/login`，本地生成设备 uuid，并用 AES 加密时间戳；成功只取 `appToken`；
   - 全程用 HTTPS 直接请求官方接口，**不打开内嵌浏览器**；
   - 密码不保存，登录成功或关闭窗口后输入框会清空；日志与界面只显示打码后的登录信息；
   - 失败会写明原因，不会循环重试、也不会假装成功：
     - **HTTP 401/403 或「可能触发风控」**：服务端拒绝，先别反复试，改用下面的「高级：粘贴密钥 / 粘贴 Cookie」；
     - **优享 `-1/-2`**：按服务端 `msg` 原文区分并原样显示——含“容量/空间不足/配额/存储不足/已满”判为容量不足（提示“容量不足：”并附 `code` 与原文）；含“登录/登陆/未授权/token/凭证”判为会话失效，清掉旧会话并提示重新登录；其余按业务失败处理，保留原始 `code` 与 `msg`。上传失败时日志还会记录配额上限、已用空间与本次文件大小，便于判断是扩容还是清理；
     - **返回 HTML / 不是 JSON**：接口被拦截或页面改版，提示里带 HTTP 状态码。
4. 接口调整或被风控时，改走**高级：粘贴密钥 / 粘贴 Cookie（降级）**：
   - 点【用系统浏览器打开登录页】自己在浏览器里登录，再从开发者工具复制 Cookie；
   - 蓝奏云：粘贴框要含 `ylogin` 和 `phpdisk_info` 两项，点【使用粘贴的 Cookie】；
   - 优享版：只需含 `appToken`；`uuid` 由程序本地生成，可省略。手里只有密钥串时，勾选粘贴框下方的「高级：这是密钥 appToken（等同于账号密码，请勿外传）」，把密钥本身粘进去，再点【使用粘贴的 Cookie】；
   - 密钥等同于账号密码，泄露就等于把网盘交给别人，请勿外传；程序只用本机 DPAPI 加密保存，界面只显示后四位，日志不落明文。
5. **登录成功后会自动读取并显示根目录的文件夹与文件**，不需要再点【刷新列表】。读取失败会直接写明原因（会话失效 / 接口拒绝 / 网络错误），不会把空列表当成“空目录”。
6. 点【测试连接】验证登录是否有效。无效会提示重新登录；被风控也会明确提示。

**关于「蓝奏优享」**：登录与上传按实测可用的优享客户端实现还原（登录接口、请求头、AES 时间戳、`appToken` 凭据、七牛分片规则），账号密码直连已由用户实测通过；界面仍标为实验性，主账号功能可优先用「蓝奏云」。

### 5.2 上传与判重

1. 选「本地待上传目录」。
2. 看上方「上传到此处：」路径条：它显示当前目标目录（例如 `根目录 / 小说 / 2026`）。列表里**文件夹和文件会同时列出**：文件夹带条目数（接口没返回时显示「—」），文件带大小和修改时间。双击文件夹或选中后按回车进入下一级，点【上一级】退一级，也可以**直接点路径条里的某一级**跳回那一级。还没登录或加载失败时，列表不会显示成“空目录”。
3. 想在新文件夹里放：先走到父目录，点【新建文件夹】，输入名称。
   - 名称不能为空，不能含 `\ / : * ? " < > |`，也不能和当前目录已有的文件夹重名；
   - 建好后窗口会刷新并自动进入新目录；
   - 失败会写明原因（权限不足、重名、接口返回的错误码），不会静默失败；
   - **蓝奏优享**目前没有可靠的新建文件夹接口，这个按钮在优享平台是灰的，点下方提示会说明原因，不会假装成功。
4. 点【扫描】：程序读网盘该目录的文件列表，逐个比对本地文件。
5. 判重规则：**网盘里已有同名、同大小的文件 → 判定重复**。重复的本地文件**不会上传**，而是被移动到你指定的「网盘重复文件」文件夹（默认放在待上传目录旁边）。
6. 蓝奏云老版：超过 100MB 的单个文件会跳过（免费账号的单文件上限），结果里写明「超过免费单文件 100MB 上限」。优享版不设本地上限，单文件限制由服务端决定（≤8MB 简单上传，>8MB 走七牛分片）。
7. 在操作区设两项，两个都会记住，下次打开沿用：
   - **并发上传**：同时传几个文件，默认 **3**，可调 **1–5**。调大上传更快，但更容易被服务端限流；网络不稳或频繁失败时调回 1–2 更稳。程序按文件数控制同时在传的数量，不会把所有文件一次读进内存。
   - **强制重传**：默认不勾。勾上就忽略本机上传成功缓存，这批文件全部重新传一遍；平时不用勾。
8. 点【上传】开始传。上传中点【停止】会同时停掉排队未开始的和正在传的文件；已经传上去的不会撤回。
9. 结果表逐行给出结论（还有原因和网盘文件 ID）：
   - **上传成功**：文件内容真的传上去了；
   - **秒传成功**：服务端已经有相同文件，程序只做登记，没有再传内容；确实成功了，只是不耗时、不重复占空间；
   - **已跳过（本机缓存）**：这台电脑之前把同一个文件成功传到同一个目录，本地记录仍匹配，这次不再重传；
   - **已跳过（>100MB）**：蓝奏云老版免费账号的单文件上限，换优享或压缩后再传；
   - **已移动到本地**：网盘里已有同名同大小文件，本地这份按判重规则移到「网盘重复文件」文件夹，没有上传；
   - **已中断**：点【停止】时还没轮到、或传了一半被打断的文件；
   - **失败**：写明原因（风控、网络、目录权限、服务端拒绝等）。单个文件失败不影响同批其它文件。
10. 结束时汇总一行：`上传完成：成功 N，秒传 M，跳过 K，失败 J，中断 X，重复移动 D`。
    - **跳过** = 本机缓存跳过 + 超过 100MB 跳过，这两类不算失败；
    - **失败**只算真正没传成的；**中断**单独计数，不混进成功；
    - 上传过程中汇总区会实时显示「已完成 x / 总数」。

**本机成功缓存什么时候失效**：缓存只记「平台 + 网盘目录 + 本地路径 + 大小 + 修改时间 + MD5 + 网盘文件 ID」，不含账号密码或 Cookie。下面任一情况都会让它失效，下次照常重新上传：

- 文件内容变了（MD5 不同），或大小变了；
- 文件的修改时间变了，哪怕内容没动（另存、复制、被别的程序重写都会改时间）；
- 换了平台（蓝奏云 ↔ 优享），或传到了网盘里的另一个目录；
- 文件改名或移动，路径变了；
- 勾了「强制重传」。

缓存文件在 `%APPDATA%\FileDedupTool\upload-cache.json`，可以直接删除；删掉只会让下次重新上传，不会影响网盘里已有的文件。

**上传到哪由什么决定**：只看「上传到此处：」这一行。点【上传】时程序会把当时的路径固定下来，这一整批文件都传到那个目录；上传过程中不会改路径（相关按钮会变灰）。所以开始前请确认路径条显示的是你想要的位置。

**记住上次目录**：下次打开窗口会沿用上次进入的目录。如果那个目录被删了、改名了或当前账号看不到，会自动回到根目录，并提示一次。

上传前会弹一次免责说明，需要你确认；第一次启用上传时也会再确认一次。

## 六、AI 分析建议（可选）

### 6.1 打开与设置

1. 点主界面 AI 分组里的【AI 设置…】。
2. 勾上「启用 AI 分析建议（可选：删除前由 AI 判断该保留哪一份）」。**不启用不影响其他功能**，AI 仅提供参考。

5. 可选：超时秒数（默认 15）、「分析组数上限」（默认 40，按浪费空间从大到小取前 N 组，越小越快越省）、token 单价（填 0 表示不估算费用）。

   - 「打开扫描结果页时自动分析」；

扫描结果出来后可让 AI 分析每组该留哪个，它给的是建议，最终删哪些、留哪些仍要你在结果页勾选确认。分析完成后会显示本次 token 用量和预计花费（前提是你填了单价）。

## 七、授权与激活

### 7.1 标准版与专业版

授权分两个等级：标准版、专业版。等级写在注册码里，激活后顶部状态显示「专业版」或「标准版」；试用期内显示「试用 · 剩余 X 天」；试用到期且未注册时显示「试用已结束，请注册」。

**标准版**解锁的全部核心能力：扫描预览、去重（内容相同、相似图片、音频相似三种方式与四种保留规则）、五步整理（改名、去特殊文件、分类整理）、合并整理、按时间整理、同名冲突与括号标题改造、回收站与撤销、长路径、占用解除、存疑确认、日志与报告导出、设置、托盘、快捷键、中英双语与日夜主题。

**专业版**在上述基础上多出：顶部搜索、AI 分析建议（含 AI 设置里的「测试连接」）、上传蓝奏（蓝奏云和蓝奏优享，含登录与 Cookie 导入）、命令行自动化（`--nogui`、本地 API）。专业功能的控件不隐藏，点进去会弹「专业版功能」提示；点「是」进入激活，点「否」继续用标准版，不会静默失效。

**免费试用 3 天，试用期内等同专业版。** 第一次运行起算，每台机器一次。**试用到期后软件全部锁定：必须注册才能执行任何任务操作**，包括扫描/预览、开始整理、去重执行、按时间整理、上传蓝奏、AI 分析、搜索、导出报告与清单、撤销。到期后主界面仍可正常打开；查看界面与已有配置、查看帮助、切换主题语言、查看授权状态与机器码、导入注册码、查看已有日志都不受影响。点任意执行类操作时会弹出注册窗口，窗口里说明原因，并可直接复制机器码、粘贴或导入 `.lic`；激活成功当次会话立即恢复，不需要重启。

试用起点同时记在注册表的一个独立键和本机文件里，读取时取更早的一份，删掉其中一份也续不了；把系统时间往回拨超过 10 分钟，直接判试用结束。已经正常激活的用户不参与试用。

**怎么获取注册码：**

1. 打开软件，点顶部那行授权状态（或点【设置 ▾】展开后点【授权】），也可以直接触发任意执行类操作，到期时会自动弹出注册窗口。
2. 窗口里显示本机机器码，点【复制机器码】完整复制（含中间的短横线）。
3. 看窗口里「获取注册码请联系」一栏，通过 **QQ：694484255（一杯好茶）** 联系作者，把机器码发过去；顶部栏作者名旁也有一个 QQ 徽标，点一下即可调起 QQ。
4. 作者按这个机器码发回 `.lic` 注册码。
5. 点【从文件导入…】选中 `.lic`，或把注册码整段粘贴进去，点【激活】；提示激活成功即可，本次会话立即恢复全部能力。

已经是标准版的，把机器码发给作者换发专业版注册码，导入激活就升级；升级会作废旧标准版剩下的有效期，新周期按新码的到期日算。

**注册后不要更换设备。** 换主板、换系统盘、重装系统都可能让机器码变化，注册随之失效，需要用新机器码重新申请。同一台机器重装系统后机器码一般不变，可用原注册码再激活一次。

**旧码。** 升级前发出的、没有等级字段的注册码一律按专业版放行，老用户不用重新申请。

## 八、搜索文件（顶部搜索行）

顶部第二行就是搜索：左边是**图标 + 「搜索」文字的同一个按钮**（点图标或点文字都行），中间是输入框，右边是 **?** 帮助按钮。

- **怎么搜**：输入文件名或文件名片段，按回车（或点搜索按钮）即可；支持 `*` 通配（例如 `报表*.xlsx`），也支持 `?` 匹配单个字符（例如 `IMG_????.jpg`）；只按文件名匹配，不搜文件内容。
- **结果在哪**：从输入框**下方**展开一个下拉列表，列是「文件名 / 路径 / 大小 / 修改时间」，最多显示 1000 条，超了会提示只显示前 1000 条。点下拉外面、按 Esc 都会收起。
- **搜哪儿**：按以下顺序选用：
  1. 本机装了 Everything 并在运行 → 直接用 Everything（速度快）；
  2. 没走通，但找得到 Everything 的命令行 → 调它来搜；
  3. 都没有 → 退回「当前处理位置」的本地扫描（只搜源文件夹里的文件）。
- **没装 Everything**：下拉顶部的状态行会明确写「未检测到 Everything，已退回本地搜索（当前处理位置）」；下拉底部有【如何安装 Everything】链接，点开是官网下载页。软件**不打包** Everything，需要的话请自行安装。
- **结果怎么用**：
  - 双击一行 = 打开这个文件；
  - 选中一行点【打开所在文件夹】= 在资源管理器里定位它；
  - 选中一行点【设为处理位置】= 把它所在的文件夹填进「源文件夹」，随后就能直接开始处理。
- 搜索中可以点【取消搜索】，搜索在后台跑，界面不会卡死。
- 点 **?** 会打开「搜索的使用说明」，可以滚动、全选复制，也可以直接点【复制全部】。
- 软件会记住上次搜索的关键词与用过的后端，下次打开自动回填。

## 十、常见问题

**扫描很慢？**
文件多、机械硬盘、杀毒软件实时扫描都会拖慢。不要拿整个磁盘做源文件夹；先用小文件夹测试。不想扫了点【停止】。

**找不到重复？**
先看「内容去重：相同内容只留一份」有没有勾上（默认是关的）。再看「最小大小(KB)」是不是把太小的文件排除了，以及「排除文件夹」有没有把目标目录排除掉。

**勾了预览却没弹出预览页？**
只有勾了任一个「去重」开关才会走预览。只做改名/整理时不弹预览，直接进确认弹窗。

**移动失败 / 删不掉？**
最常见是文件被别的程序占用（微信、QQ、网盘同步、杀软）。退出对应软件再重试，或勾「遇到占用自动尝试解除」。详细原因点【查看日志】看最后几行。

**撤销后文件没回来？**
先看撤销汇总属于哪一类：
- 「已从回收站还原」：成功回到原路径；
- 「回收站中找不到」：回收站里没有对应条目（可能被别的清理工具删了）；
- 「回收站已被清空」：回收站整体为空，没法还原；
- 「还原失败：原位置已有同名文件」：程序不覆盖，回收站原件仍在，可手动处理同名文件后再还原；
- 「目标已不存在」/「原位置已占用」：这是移动/改名项的旧分类。

**表格里说「保留最新」，为什么留下的是旧的？**
「最新/最旧」比的是**文件修改时间**，不是拍摄时间。复制、下载往往会改掉修改时间。

**上传蓝奏失败？**
按提示分三种：
- 提示「请先登录或导入 Cookie」→ 还没登录；
- 提示「Cookie 失效或触发风控」→ 重新登录一次；
- 上传成功但列表没刷新 → 点【刷新列表】重新读网盘目录。
遇到 403 或限流，程序会自动等 2 秒重试一次，仍不行才标「失败」并写明原因；单个文件失败不影响同批其它文件。结果里的「秒传成功」「已跳过（本机缓存）」都是正常的成功/跳过，不是失败。
优享版本身是实验性的，失败时优先换回蓝奏云。

**AI 测试连接失败？**
先检查接口地址是否填到 `/v1`、密钥有没有多余空格；超时就把「超时（秒）」调大；公司网络或代理可能拦截，可换本地 Ollama 试。

**帮助窗口里搜不到关键词？**
帮助窗口的搜索框是按字面匹配的，换个更短的关键词；输入后按回车会跳到第一个命中。

**检查更新没反应，或者提示检查失败？**
每次启动程序都会在后台悄悄查一次，不挡界面；查不到就静默结束，启动不受影响。想让它明说，就点【设置 ▾】→【检查更新】。
国内访问 GitHub 有时不通，超时后会提示「可手动到 Release 页面下载」，照提示去网页自己下载即可，不影响其它功能。
同一个版本只会问一次，点了「跳过此版本」就不再问它；出了更高版本仍会提示。详见「十四、自动更新」。

**网盘查重会不会自己删文件？**
不会。默认只列清单，要删得你自己勾选、再点【删除勾选项…】，而且每个文件都单独确认，写明路径和所在目录。能删到什么程度、删完能不能恢复，见「十五、网盘查重（远端）」。

## 十一、全盘查重

主界面的「整理方式」分组里有一个【全盘查重…】按钮，打开一个独立窗口。它和第三步的「查重」不是一回事：第三步只看你选的源文件夹，全盘查重会扫描整个磁盘（默认所有固定磁盘和移动磁盘/U 盘），用来找散落在各处的重复文件。这个功能属于**专业版**；标准版点击时会弹出专业版提示。

### 11.1 选磁盘

1. 窗口左上是磁盘列表，列出**本地固定磁盘和移动磁盘（U 盘、移动硬盘、读卡器）**，每行显示盘符、卷标、类型、总容量、可用容量；网络盘、光驱、RAM 盘不会出现，也不能扫描 OneDrive 这类网络位置。
2. 每行左边的大复选框可以直接点，点整行也能切换勾选；列表上方有【全选】【全不选】。默认全部勾选，勾选状态会记住，下次打开沿用。
3. 没插介质、暂时未就绪的盘符仍会列出来，但复选框禁用，类型后标「未就绪（未插入介质）」，不参与扫描。盘符多时窗口会向下加高，列表本身不套内部滚动条。
4. 「扫描选项」里可以调：
   - **最小大小(KB)**：默认 1，小于这个值的文件不参与；填 0 表示不按大小过滤。
   - **包含 0 字节文件**：默认不勾，空文件不参与。
   - **只做 64KB 快筛**：默认不勾。勾上更快，但两个文件只要前 64KB 一样就可能被当成重复，**不建议**在真正要删的时候用。
   - **优先用 Everything 索引加速**：**默认不勾**。即使电脑上装了 Everything，也不一定更快：遇到文件很多的大目录，查询结果会退化成按子目录一片一片查，反而比程序自己遍历更慢。日常全盘扫描建议保持关闭；只有明确只扫某个小范围（已知目录、文件不多）时，再手动勾上。
5. 点【开始扫描】。扫描中能【暂停】【继续】【停止】。停止后已经扫出来的结果仍然可以看、可以导出。

### 11.2 哪些目录永远不扫（不可关闭）

下面这些是硬排除，**没有开关**，用来防止误删系统文件：

- 目录：`Windows`、`Program Files`、`Program Files (x86)`、`ProgramData`、`$Recycle.Bin`、`System Volume Information`、`Recovery`、`PerfLogs`、`$WinREAgent`、`Config.Msi`、`Boot`、`EFI`。判断方式是「盘符根 + 目录名」前缀匹配、忽略大小写，所以 `C:\Windows`、`D:\Windows`、`E:\Program Files\…` 都会被挡住，而不只是系统盘。
- 文件：`pagefile.sys`、`hiberfil.sys`、`swapfile.sys`、`DumpStack.log*`。
- 程序自己所在的目录，以及 `%APPDATA%\FileDedupTool`、`%LOCALAPPDATA%\FileDedupTool`。

扫描时遇到没有权限的目录会跳过并计数，结果顶部会显示「跳过目录 N」；不会弹 UAC，也不需要管理员权限。

### 11.3 扫描要多久

时间取决于文件数量和磁盘速度，程序在扫描时显示**已扫描文件数、已发现重复组数、当前目录**，进入哈希阶段后还会显示「预计剩余约 …（估算）」。估算只是参考，会随实际速度变化。全盘扫描通常是**分钟级到十几分钟**，第一次扫系统盘之外的盘会慢一些；嫌慢可以先取消勾选大容量盘，分盘扫。

### 11.4 结果怎么看

- 结果按**重复组**显示。每组有一行组标题：大小、重复份数、可释放空间；组下面是每个文件一行：完整路径、大小、修改时间、创建时间。
- 绿色标出的是程序**建议保留**的那一份：优先选路径最短、目录层级最浅、文件名里没有 `(1)`、`副本`、`copy`、`- 副本` 这类副本标记的。
- 点【建议保留（其余待删）】会把每组建议保留的那份之外的文件都勾上（只勾选，**不会自动删**）。
- 顶部汇总：重复组数、可释放空间、跳过目录数、扫描耗时。
- 排序：点「大小 / 修改时间 / 创建时间」列标题可以排序，再点一次反向；点「文件路径 / 重复组」按路径排。
- 筛选：右上角输入框可以按扩展名（如 `.jpg`）或目录关键字过滤；右边「只看 ≥ (KB)」只看大于等于这个大小的组。
- 列表是虚拟模式的，几十万行也只按屏幕上能看到的行去画，不会卡死。

### 11.5 删除与撤销

1. **默认一个文件都不删**。只有你自己勾选、再点【删除勾选…】才会动文件。
2. 点删除后会先校验：**同一组里至少要留 1 个文件不被勾选**，全组都勾上会被拦下并提示，不会删。
3. 校验通过会弹二次确认，写明「将 N 个文件移入回收站，可释放 X」。确认后才执行；固定 NTFS 盘的删除走回收站，不是永久删除。开启「可移动盘使用永久删除」后，确认框会写明「将永久删除 N 个文件，不进回收站，无法撤销」，并且必须勾选「我明白无法恢复」才能点确认。
4. 删完可以点窗口里的【撤销本次删除】，或回主界面用原来的「撤销」入口，从回收站按原路径还原（不覆盖已有文件）。永久删除的文件不在回收站，撤销会跳过并提示「该项为永久删除，无法撤销」，结束时会给出「还原 N 个、跳过 M 个（永久删除）」的实际结果。
5. 筛选状态下点删除，只会删**当前列表里看得见且勾选的**文件，隐藏的勾选不会被执行；确认框里的 N 和 X 也只算这些。
6. **U 盘/移动磁盘和非 NTFS 卷通常没有回收站**。默认情况下这些位置的文件会被跳过，日志写 FAIL「没有回收站」，不会偷偷改成永久删除。确实要清理这类盘时，可勾选扫描选项区的「可移动盘使用永久删除（不进回收站）」：开启后这些位置的文件会被**永久删除**，不进回收站、无法撤销；删除前必须勾选「我明白无法恢复」。固定 NTFS 盘始终走回收站，开关对它们无影响。同时选中固定盘和移动盘时，确认框会分开写明「X 个进回收站、Y 个永久删除」。勾选这类盘时，磁盘列表下方会显示红色风险提示。

### 11.6 导出

- 【导出 CSV】：列为「组号、文件路径、大小(字节)、修改时间、创建时间、建议保留、勾选状态」，表头带授权标识，末尾附跳过目录数与扫描耗时。
- 【导出 HTML】：与普通查重报告同一套配色风格，含汇总、每组明细和授权水印。

### 11.7 注意事项

- 全盘扫描会读很多文件，机械硬盘上会比较久；扫描期间可以正常用电脑，但别同时跑大型磁盘任务。
- OneDrive、网盘同步目录、网络位置**不支持**（不在固定盘枚举范围内，或被当成占位文件）。
- **不要对系统盘做大批量删除**。就算程序挡住了系统目录，也别在 `C:\` 上一次勾几千个文件删——先小范围试一组，确认建议保留项靠谱再扩大。
- 回收站也有容量上限，删得太多可能挤掉更早的回收站内容；重要数据先备份。
- U 盘、移动硬盘和 FAT32/exFAT 卷通常没有回收站。默认不删除这些位置的文件（只提示跳过）；只有在手动开启「可移动盘使用永久删除（不进回收站）」后才会永久删除，且无法撤销——这是明确的风险，重要文件先备份。扫描、预览和导出不受影响。
- 「只做 64KB 快筛」只适合先摸底，别用它来决定删文件。

## 十二、注意事项

**一、被占用的文件夹，先解除占用，不行再退出程序。**
微信、QQ 的聊天文件目录、网盘同步目录，以及正在被编辑器或杀毒软件扫描的文件夹是最常见的情况。被占用时会列出占用进程名和 PID，你同意后才结束对应的**用户程序**，系统进程和资源管理器不会被结束。不想每次询问，可以勾「遇到占用自动尝试解除（仅结束用户进程）」。
同意结束前先保存正在编辑的文档；占用方是网盘或云文件提供程序时，先暂停同步。

**二、默认的「冲突时删除本文件」会删文件。**
第一/二步改名撞名、第五步移动撞名，都会按这个策略删掉当前文件，内容不同也照删。不确定就改成「冲突时自动重命名」或「冲突时保留两者」。永久删除不可恢复，需要后路就保持「删除到回收站」。

**三、第三步默认关闭。**
它按八类规则删「无意义文件名」，已豁免日期（`20240115`）、纯年份（`照片2024`）和设备编号（`DSC01234`），但规则偏激进。要开就先预演。

**四、超过 260 字符的长路径。**
扫描、查重、移动、硬链接、按时间整理、分类整理、撤销都支持超长路径，界面和日志里显示的仍是正常路径；目标路径超长时会自动建深层目录。建议在 Windows 里开启长路径支持，否则**资源管理器和回收站**可能不认超过 260 字符的路径；即使没开，本程序自己的文件操作仍可用。点【检测环境】查看状态与实测结果。极少数情况仍可能失败：路径接近系统上限、目标目录不允许创建、或回收站不支持该位置。

**五、不要处理整个磁盘根目录。**
程序会直接拒绝；先选具体文件夹。

**六、跨磁盘整理会慢。**
系统要先复制再删源，大文件需等待较久；中途不要强行关程序，避免留下半个副本。

**七、上传蓝奏依赖蓝奏账号。**
上传需要登录蓝奏账号并遵守对方的使用条款；软件不保存账号密码，只在本机加密保存登录状态 Cookie，另存一份不含凭据的上传成功缓存（路径、大小、时间、MD5、网盘文件 ID）。网盘重复文件只做「同名同大小」判定，不读取网盘文件内容。

**八、AI 是可选项，密钥由你自己保管。**
接口密钥保存在本机设置里，不上传到任何第三方；AI 只给建议，不会自动删文件。产生的 token 费用由你的服务商收取，软件只按你填的单价做估算。

## 十三、两个版本：发行版与测试版

同一套程序只出两个文件，**产品名和版本号完全一样**（一杯好茶.文件整理 v1.1.1），只有文件名不同：

| 文件名 | 给谁用 | 账号信息 |
| --- | --- | --- |
| `一杯好茶.文件整理-发行版.exe` | 对外分发、上传网盘/发布页 | **不含任何账号、密码、Cookie、token**；打包完成后会自动扫一遍产物，扫到任何凭据痕迹就判失败并删掉产物 |
| `一杯好茶.文件整理-测试版.exe` | 作者自己测试 | 内置蓝奏优享账号，打开「上传蓝奏」会自动登录，不用每次输；请勿外发 |

测试版里的账号是**加密存放**的，不是明文：

- 打包时用随机盐 + 20 万轮密钥派生算出密钥，再用 AES-256-CBC 加密，另带一段 HMAC-SHA256 校验；
- 程序运行到需要时才在内存里解密，只有在测试版里才会碰到这段数据；
- 加密只解决「明文躺在文件里被搜到、被误发」的问题，**挡不住专门逆向的人**。所以测试版仍然只给自己用，不要上传、不要转发。

另外几点：密码不会写进日志、不会显示在界面上、不会写进导出的 CSV/报告；测试版自动登录失败时，会退回手动登录并写一条日志（日志里只有失败原因，没有密码）。

## 十四、自动更新

自动更新**不需要自建服务器**，直接用 GitHub 的 Releases 页面。

**什么时候查。** 默认每次启动都会在后台查一次，不挡界面、不卡启动。你也可以点【设置 ▾】→【检查更新】手动查。查询地址是 GitHub 的公开接口，不需要 token；每次查询结果在本机缓存 **18 小时**，同一时间段内不再重复请求（匿名接口按 IP 限制每小时 60 次，程序不会循环请求）。

**检查方式可以改。** 点【设置 ▾】→【软件更新…】，有两个选项：

| 选项 | 启动时 | 想更新时怎么查 |
| --- | --- | --- |
| 启动时检查并提醒（默认） | 后台查一次，有新版本才提醒 | 也可以随时点【检查更新】手动查 |
| 仅手动检测 | **完全不联网**，不查也不提示 | 点【软件更新…】里的【立即检测更新】，或【设置 ▾】→【检查更新】 |

选完点【保存】立即生效，**重启后保持不变**。手动检测不会「点了没反应」：发现新版本会弹提示窗口；已经是最新会明确提示「已是最新版」；失败会说明原因（超时、被限流、网络不通等）并给出 Release 页面地址，可自己去网页下载。跳过过的版本仍然不会再提示，出了更高版本照常提醒。

> 说明：卡死问题修复后，扫描结果改为分批显示——几千组时窗口仍可移动、可取消，也能看到「正在填充结果 x/y」的进度。

**查到新版本会怎样。** 只有远端版本比本机高才会弹窗，窗口里写明：新版本号、安装包大小、发布时间、更新说明；四个按钮：

| 按钮 | 做什么 |
| --- | --- |
| 下载并更新 | 下载到临时目录，显示进度，可随时取消 |
| 查看说明 | 用系统浏览器打开这个版本的发布页 |
| 跳过此版本 | 记住这个版本号，以后不再提示它；出了更高的版本仍会提示 |
| 稍后 | 这次不处理，下次启动再查 |

**下载和校验。** 下载完成后，程序按发布信息里的 `sha256:` 摘要逐字节校验；对不上就删掉下载的临时文件，并写明原因（摘要不对、文件不完整等），不会拿一个坏文件去替换。

**怎么替换。** 只有你点了确认才会替换，程序不会偷偷换：

1. 先把当前正在运行的 exe 改名成 `.old`；
2. 把校验通过的新文件放到原位置；
3. 启动新版本，旧进程退出；
4. 下次启动时顺手清掉 `.old`。

中途任何一步失败（文件被占用、没有写权限、新文件启动不了），会把 `.old` 改回原名，**退回原来的状态**，不会出现「旧的没了、新的也没成」的情况。

**网络不通怎么办。** 国内访问 GitHub 经常超时，程序 8 秒就放弃，不会一直转圈；手动检查时会提示「可手动到 Release 页面下载」并给出链接，自己下载后覆盖原文件效果一样。启动时的自动检查失败只写日志，不打扰你。

## 十五、网盘查重（远端）

主界面底部的【网盘查重…】打开独立窗口。这是**专业版**功能，标准版点击会弹专业版提示。

**它比什么。** 只比「**同名 + 同大小**」：名字相同（不分大小写）、字节数也相同，就归为一组，默认把多余的标成可删除。**不读文件内容、不算哈希**，所以两个名字和大小都一样、内容其实不同的文件也会被列出来——删之前请自己看一眼。

**怎么扫。** 从上往下逐层展开远端目录（分页读完再进下一层），窗口显示已展开文件夹数、找到的文件数、当前目录；随时可以点【停止】。默认最多展开 **8 层**（1~64 可调），到顶会写明「已达 N 层上限，更深目录未展开」；个别目录读失败会跳过并计数，不会让整次扫描白跑。

**结果怎么看。** 按组显示，每组一行组标题（文件名、大小、份数），组里每个文件一行：完整路径、大小、修改时间。**绿色「建议保留」**的那一份优先选层级最浅的，其次路径最短的，再其次按字典序；这个规则和本地查重的「保留路径最短」一致。想省事可以点【勾选可删除项】，它只勾选、不删除。

**删之前要知道的两件事**（两个平台不一样，程序不会混着说）：

| 平台 | 删除后能恢复吗 | 程序怎么处理 |
| --- | --- | --- |
| 蓝奏云（老版） | 能，进网页回收站（`pc.woozooo.com` → 我的网盘 → 回收站） | 确认框写明「移入蓝奏云回收站，可在网页端恢复」 |
| 蓝奏优享 | **不能**，现有接口没有回收站/恢复能力，删除即永久删除 | 先弹一次「确认永久删除？」的重确认，必须勾选「我明白无法恢复（永久删除不进回收站）」才能继续，然后再逐个确认每个文件 |

**删除流程。** 默认一个文件都不删。点【删除勾选项…】之后：

1. 先按平台做上面那层确认；
2. 再对**每个文件单独确认**，写明要删的文件路径和它所在的目录；
3. 分批执行，每批 20 个，批与批之间停 1.5 秒；
4. 每一步都写日志；失败的单独记，结束时给「成功 N 个，失败 M 个」，并列出失败明细（最多 30 条，完整的写进 CSV）；
5. 中途可以停下来，已经删掉的不会撤回，没轮到的保持原样。

所以不会出现「全部成功」一笔带过的情况——有失败就一定看得到。
