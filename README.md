## 功能

- **内容去重**：按「大小 → 内容」比对，文件名不同、内容一样的文件也能找出来；删除前再核对一次文件有没有被改过。

- **相似图片去重**：连拍、轻微修图这类「看着几乎一样」的图片也能抓到，阈值可调。

- **音频相似去重（实验）**：同扩展名、时长接近的音频归为一组，适合清理下载目录里的重复歌曲。

- **硬链接合并**：不删文件，把重复文件变成指向保留文件的硬链接，看着还在、实际不多占空间（仅同一磁盘内有效）。

- **五步整理**：去前缀序号、去后缀序号、删除无意义文件名的文件、去只读属性、按类型/后缀/关键字/正则分类归档。

- **按时间整理**：按拍摄时间或文件时间，自动分进「年 / 月 / 日」或「年 / 周」文件夹；可选移动或复制，同名冲突有比对去重、自动加序号、跳过三种处理。

- **先看后做**：扫描预览、预演模式，改文件之前先给清单；结果可导出 HTML 报告或 CSV。

- **可撤销**：删除默认进回收站，撤销时按操作清单反向还原，并自动从回收站找回删除项；原位置已有同名文件时不覆盖。

- **顶部搜索**：装了 Everything 就走它，快；没装就退回软件自带扫描，能用但慢一些。

- **AI 分析建议**（专业版）：让 AI 在重复文件组里建议留哪一个，只给建议，删不删仍由你勾选。

- **上传蓝奏**（专业版）：把整理好的文件传到蓝奏云，网盘里已有同名同大小的文件会挑出来，不重复上传。

- **规则测试器**：填一段文件名，先看关键字或正则会不会命中、会被改成什么名字，不动任何文件。

- **其他**：中文/English 界面、浅色/深色主题、托盘最小化、操作日志、长路径支持。

所有会改动文件的操作默认都先出清单，不会上来就删。

## 适用场景

- **小说和电子书下载了一堆，版本也一堆**：TXT、EPUB、MOBI、PDF 混在同一个目录里，同一本书有精校版、扫描版、转格式版，还夹着几次重复下载的同一份文件。先用「内容去重」把字节完全一样的清掉，再用「相似图片去重」处理同一套封面，剩下的按书名、作者归位，这就是最常说的小说去重整理。

- **从零搭一个电子书书库**：把攒了多年的书集中到一个目录，按作者或书名分文件夹，新下载的用「按时间整理」按月归档，慢慢长成一个自己看得懂的电子书书库。

- **小说书库的日常维护**：每周把新下载的书过一遍，去重、改名、归位；旧版本该清的就清。全程可以先扫描预览出清单，确认没问题再动手，删掉的默认进回收站，撤错了还能找回。

- **整理完直接上传蓝奏留存**：本地空间不够、又不想丢书的时候，去重整理上传蓝奏可以连着做——先把重复文件清掉，再把整理好的书库传到蓝奏云，网盘里已有同名同大小的文件会被挑出来跳过，不重复占空间。

## 系统要求

- 64 位 Windows 10 / 11。

- 不需要安装 .NET 运行库，双击即可运行。

- 可选：**WebView2 运行时**（专业版「上传蓝奏」的窗口内登录用）。

- 可选：**Everything**（专业版顶部搜索加速用）。

**环境不具备时怎么办**

- **32 位系统、Windows 7 及更早系统**：程序跑不起来，需要换 64 位的 Windows 10/11。

- **没有 WebView2**：上传蓝奏的登录窗口打不开。到微软官网下载「WebView2 Runtime」安装（选 Evergreen 版），装完把本软件关掉重开；不装也能用，登录会退回「系统浏览器登录 + 手动粘贴 Cookie」。

- **没装 Everything**：搜索会退回软件自带的扫描，功能不受影响，只是慢一些。想快就装上 Everything 并让它在后台运行，再重开本软件。

## 首次运行被 Windows 拦截

从网上下载的 exe 会带「来自互联网」标记，当前版本没有购买代码签名证书，Windows SmartScreen 可能弹出蓝色的「Windows 已保护你的电脑」。这不是杀毒软件报毒，只说明系统还不认识这个来源。

1. 在蓝色窗口点「更多信息」，再点「仍要运行」。
2. 不放心就先核对 SHA-256，一致再运行。
3. 核对无误后可右键文件 → 属性 → 勾选「解除锁定」，之后一般不再提示。

**校验 SHA-256（PowerShell）**

```powershell
Get-FileHash -LiteralPath ".\一杯好茶.文件整理.exe" -Algorithm SHA256
```

把输出与发布页上写的大小、SHA-256 逐位对比，一致即说明文件完整、未被篡改。当前版本：67,503,318 字节，SHA-256 `FE49D9EB8B89E456378FCE07BFB098AA9E008E13AB02D10A867F5BA2637633FC`，未签名。

如果杀毒软件误报，先核对哈希确认来源，再把该文件加入信任/白名单，必要时把样本提交给厂商复核；不要为了运行程序关闭整个杀毒软件。

## 常见问题

**双击没反应？** 先看是不是被杀毒软件拦了，再确认系统是 64 位 Windows 10/11。

**删除的文件去哪了？** 默认进 Windows 回收站，点【撤销上次任务】可以还原；改成「永久删除」就不进回收站，只能靠事先备份。

**提示某些文件删不掉？** 部分移动盘、网络盘不支持回收站，这类文件会删除失败并写进日志，不会偷偷改成永久删除。

**改名后文件不见了？** 检查「冲突时删除本文件」这个默认策略：改名撞上已有同名文件时，它会把正在改名的文件删掉。第一次用建议先改成「自动重命名」或「保留两者」，或者先勾「预演模式」跑一遍。

**照片都进了「未知时间」？** 文件的拍摄时间和修改时间都不可用时会这样，先在预览页看「时间来源」列，再决定要不要继续。

**试用到期了怎么办？** 软件会锁定所有执行类操作，必须注册后才能继续。点顶部授权状态或任意执行按钮弹出的注册窗口，复制机器码，通过上面的联系方式联系作者获取 `.lic`，导入激活后当次会话立即恢复，不用重启。

**换电脑还能用原来的注册码吗？** 不能。授权绑定设备，换设备后需要用新机器码重新申请。

**会上传我的文件吗？** 不会。去重和整理全在本机完成；只有你主动使用 AI 分析或上传蓝奏时，相关请求才会发到你配置的接口或蓝奏云。
